# 🌦 Weather Anomaly Detector

## 📌 Project Overview

This project detects unusual weather patterns using Python and NumPy.
It analyzes temperature, humidity, and rainfall data to identify anomalies using statistical methods.

---

## 🛠 Technologies Used

* Python
* NumPy

---

## 📊 How It Works

1. Generates random weather data (temperature, humidity, rainfall)
2. Introduces artificial anomalies
3. Calculates mean and standard deviation
4. Applies Z-score normalization
5. Detects anomalies based on threshold values
6. Displays anomalous days and summary statistics

---

## 🎯 Features

* Detects abnormal weather conditions
* Uses statistical approach (Z-score)
* Highlights most extreme anomaly days
* Provides overall anomaly percentage
